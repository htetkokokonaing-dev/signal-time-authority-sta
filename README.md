# Signal-Time-Authority (STA) Framework

**Signal-Time-Authority (STA)** is a pre-commitment controllability framework for runtime AI oversight.

The central idea is simple:

> Runtime monitoring is not automatically runtime control.

Runtime oversight becomes control-relevant only when four conditions remain jointly adequate before an externally consequential commitment event:

1. **Usable signal**
2. **Remaining time**
3. **Effective authority**
4. **Valid intervention policy**

If these conditions are no longer available, runtime monitoring may still support audit, explanation, diagnosis, or post-hoc review, but it may no longer provide meaningful intervention or control.

## Non-Claim

STA is not presented as a proof of AI safety.

The current PublicRelease v1.0 series:

- does not claim real-world deployment validation,
- does not replace domain-specific safety standards,
- does not replace certification or regulator review,
- does not provide legal advice,
- does not claim that monitoring alone is control,
- does not claim that any intervention ladder is universally optimal.

STA should be read as a falsifiable research framework and public preprint series.
